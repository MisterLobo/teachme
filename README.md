# TeachMe — Private 1-on-1 Tutoring Platform

A secure, end-to-end encrypted platform connecting learners with tutors for live, one-on-one sessions. Every call, message, and shared piece of content is private — the platform cannot read your session data.

---

## For Non-Technical Readers

### What is it?

An online tutoring platform where students find tutors, book sessions, and attend live video lessons — all with strong privacy guarantees. Think Zoom for tutoring, but built so the platform can't listen in.

### What You Can Do

**Sign up and log in** using your email, a security key (passkey), or a PIN — no password to remember or leak.

**Find the right tutor** by describing what you want to learn in plain language. The platform suggests tutors based on subject, style, availability, and schedule.

**Book a session** at a time that works for both you and the tutor. The platform handles scheduling, time zones, and payment.

**Attend a secure live session** with built-in video, audio, and screen sharing. Everything is encrypted end-to-end — your key, your device, your private session.

**Manage your account** across devices. Your encryption keys follow you securely.

**Pay as you go or subscribe.** Try all features free for 30 days.

### Privacy By Design

Most video platforms can see your video, hear your audio, and read your messages. TeachMe encrypts everything end-to-end. Here's how it stays private:

- Your encryption keys are **generated on your device** and never sent to the server in plaintext
- Each session generates a **unique access code**, encrypted with both participants' keys
- Media frames (video/audio) are encrypted **frame-by-frame** using ephemeral session keys
- If you lose a device, **recovery codes** let you restore access without a central backdoor
- The database uses **row-level security** — even a direct database query can't see another user's data

## For Technical Readers

### Architecture Overview

```
                         ┌─────────────────────┐
                         │   Web Client         │
                         │  (Next.js, WASM)     │
                         └─────────┬───────────┘
                                   │ HTTP / WS
                                   ▼
┌──────────────────────────────────────────────────────┐
│               API Gateway (NestJS)                    │
│  Auth guards │ Rate limiting │ WS bridge │ gRPC client│
└──────┬───────────────────────────────┬───────────────┘
       │ gRPC                           │ gRPC
       ▼                                ▼
┌──────────────────────┐    ┌──────────────────────────┐
│   Core Backend (Go)  │    │   Media Service (Rust)    │
│   Fiber, bun ORM     │    │   mediasoup, socket.io    │
│   PostgreSQL, Redis   │    │   OPAQUE auth server     │
│   Asynq task queues   │    │   GStreamer recording    │
│   Stripe integration  │    └──────────┬───────────────┘
│   Vault secrets       │               │
│   Qdrant, Neo4j       │               │ WebRTC
└──────┬────────────────┘               ▼
       │ gRPC                   ┌─────────────────┐
       ▼                        │  Browser/Client  │
┌──────────────────────┐        │  (mediasoup)     │
│   AI Service (Python) │        └─────────────────┘
│   FastAPI, LangGraph  │
│   Ollama, Fastembed   │
│   NATS JetStream      │
└──────────────────────┘
```

**Service Authority**: The Go backend is the sole authority over data — it owns all business logic and has exclusive write access to the database. Other services request mutations through Go or are given read-only access.

**Communication**: gRPC for synchronous calls, NATS JetStream for async events. All traffic is TLS/mTLS encrypted.

### Quick Start

```sh
# Infrastructure
docker compose up

# Web client
bun web:dev

# API gateway
bun api:dev

# Media service
cd apps/signal && cargo loco watch --server-and-worker

# AI service
cd apps/assistance_ranking && ./start.sh

# Backend tests
cd apps/dbal && go test ./src/...

# Integration tests (requires running infrastructure)
cd apps/dbal && go test -tags integration ./src/...
```
